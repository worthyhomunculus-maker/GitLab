# Список недоступных узлов

ФИО: Мирошниченко Алексей Юрьевич
Вариант: 7

## Назначение

Консольное приложение на C# для формирования списка
недоступных узлов на основе заранее заданных данных.

Программа не выполняет сетевые запросы.

## Реализованные функции

1. Отбор узлов, у которых Available == false.
2. Вывод узлов в формате:
   DOWN: Name; available=Available
3. Подсчёт количества отобранных записей.

## Разрешение конфликта

В ветке feature/a был добавлен префикс DOWN.
В ветке feature/b был добавлен вывод признака available.

При слиянии обе ветки изменили одну строку return
в Formatter.cs. Конфликт разрешён вручную:
обе части форматирования объединены в одной строке.

## Запуск

dotnet build
dotnet run

## Проверки

Основной набор:
DOWN: nodeB; available=False
DOWN: nodeD; available=False
Count: 2

Пустой массив:
Count: 0

Все узлы доступны:
Count: 0

Один узел x / false:
DOWN: x; available=False
Count: 1

Сводка вычисляется по отобранным записям.
